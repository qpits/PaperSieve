Embedding

torch needs nothing beyond the accelerator's own install target; onnx and openvino need their extra installed (see the README's Setup section). auto detects the device. Two quirks worth knowing: ROCm builds of torch identify as cuda, so AMD users pick cuda here — rocm is an ONNX Runtime provider name only. And npu only exists for openvino, where it is expected to fail on most embedding models (its compiler requires static shapes). An invalid runtime/device pair is rejected when the run starts.

Advanced

How many texts are encoded at once. Leave empty to pick one from the detected device (64 on CUDA/ROCm/XPU/MPS, 16 on CPU); lower it if you run out of GPU memory.

Advanced

Texts per request to the embeddings endpoint. Defaults to 96; lower it if the provider rejects large batches.

Tiers

With percentile these are percentile cutoffs (0-100) among that query's own results; with absolute they're raw cosine similarity scores (roughly 0-1).
